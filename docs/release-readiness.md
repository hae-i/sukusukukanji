### 콘텐츠 해석 시 주의할 점

실제 학습에 연결된 것은 초등 1,026자이며, **전체 2,136자 학습이 구현된 상태가 아닙니다.** 중등 1,110자는 배정 목록이며 학습 카드·퀴즈는 아직 연결하지 않았습니다. 초등도 모든 글자에 단어·예문을 제공하는 상태는 아닙니다. 중학교의 350/400/360자 배정은 학습지도요령의 범위를 참고한 앱 자체 배정이며 공식 문자별 학년 배당표가 아닙니다.

예시 단어/한국어 연결이 없는 것은 가짜 데이터로 채운 placeholder가 아니라 의도적으로 숨긴 optional 항목입니다. 모든 한자에 억지로 연결을 만들 필요는 없지만, 현재 한국어 연결 콘텐츠가 8자에만 있다는 점은 앱의 핵심 경험을 확장할 때 우선 검토해야 합니다.

## 현재 구현의 제한 — 모두 출시 필수 기능은 아님

- **미완료 세션 재개:** 퀴즈 진행 중 강제 종료하면 해당 세션은 처음부터 시작합니다. 이미 완료된 학습 기록은 보존합니다.
- **백업은 자동 병합이 아님:** 다른 기기에서 백업이 바뀌면 사용할 기록을 선택합니다. 복원은 기기 기록을 교체하며, 상시 실시간 다기기 동기화는 구현하지 않았습니다.
- **백업 제외:** 광고 횟수/이용권, 구매 권한, 아이콘 선택/확인 상태, 온보딩 설정. 아이콘 해금은 학년 완료 기록으로 다시 계산합니다. 구매 복원은 별도 Google Play 기능이 필요합니다.
- **광고 이용권:** 기기 로컬 저장 기반이며 SSV 서버 보상 검증은 없습니다. 사용하지 않은 이용권은 재실행 후 유지하지만, 보상 저장 실패 상태로 앱 프로세스가 종료된 경우 완전 복구를 보장하지 않습니다.
- **광고 모드:** debug/profile은 테스트 광고, release는 명시적으로 live 설정 전까지 광고/일일 제한이 꺼져 있습니다. 실제 광고 출시 빌드에는 live 설정과 실제 ID가 필요합니다.
- **검증 범위:** 패키지는 Dart ^3.13.3과 호환되도록 맞췄지만 이 환경의 직접 실행 검증은 Dart 3.13.5 / Flutter 3.47.6입니다. 사용자 Windows PC의 Dart 3.13.3 실행과 Android 실기기는 별도 확인 대상입니다.
- 검색/정렬/학년 선택은 탭 이동 동안 유지하며 앱 재실행 시 기본값으로 돌아옵니다. 내 한자는 학습 콘텐츠만 표시하고 중학교 배정 목록을 학습 카드로 취급하지 않습니다.

## 현재 보류하거나 요청 범위에 포함하지 않은 기능

- iPhone 출시 및 Android↔iPhone 구매 연동: 사용자 결정에 따라 현재 대상 아님
- TTS/AI 발음 음성 파일: 가능성만 논의했으며 재생·생성·검수·저장은 구현하지 않음
- 따라쓰기/필기 정오 판정: 설명만 했으며 미구현
- 복잡한 SRS, JLPT 과정, OCR, AI 채팅, 친구·랭킹·재화 상점·경쟁 기능: 현재 범위 밖
- 별도 FastAPI 서버/Cloudflare Worker: 현 로그인·진도 백업 요구에는 필수 아님. Supabase Auth + DB 직접 연결 구조로 준비
