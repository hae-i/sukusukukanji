# Phase 1–8 구현 설계

## 유지한 원칙

저장소 원본 `AGETNS.md.txt` 안의 프로젝트 지침을 적용했습니다. Flutter/Dart, local-first, 작은 검증 샘플, feature 중심 구조를 유지합니다. 검증 샘플 10자로 흐름을 검증한 뒤, Phase 7에서 출처를 대조한 80자를 정적 JSON으로 확장했습니다.

## 상태와 화면 이동

Flutter `ChangeNotifier` 한 방식입니다. `AppController`가 콘텐츠·사용자 기록·설정을 로딩하고 세션 생성과 저장을 조정합니다. `SessionController`가 카드 위치, 퀴즈 선택, 저장 중/실패/결과 상태를 관리합니다. 탭·필터·온보딩 페이지처럼 화면에만 필요한 상태는 작은 StatefulWidget에 둡니다.

기본 `Navigator`로 충분하므로 별도 라우터 패키지는 없습니다. 하단 탭은 홈/학습/내 한자 3개입니다. 학습·복습은 별도 경로로 열리고 내부 카드→퀴즈→결과는 하나의 세션 상태로 전환합니다. `/kanji/:id`, `/grades`, `/settings`, `/icons`는 보조 경로입니다.

앱 시작 시 콘텐츠·SQLite·preferences 로딩에 모두 성공해야 온보딩/홈을 표시합니다. 오류를 기본 빈 기록으로 덮어쓰지 않습니다. 로딩 재시도와 dispose 이후 비동기 응답을 처리합니다.

## Phase 2: 학습과 퀴즈

- `SessionPlanner`: 첫 미완료 레슨에서 authored order 순 최대 5자. 레슨 순서를 랜덤으로 섞지 않습니다.
- `QuizGenerator`: 각 한자를 최소 1문제 평가하고 총 최대 8문제까지 유형을 추가합니다. 샘플 5자는 8문제, 1자 복습은 가능한 3종 3문제입니다.
- 뜻, 대표 훈독(없으면 대표 음독), 단어 읽기. 모두 JSON의 정답과 다른 검증 항목의 값에서 선택지를 구성합니다. 대상의 다른 유효 읽기는 오답 풀에서 제외합니다.
- 선택지와 문항 순서는 변할 수 있지만 학습 사실은 생성하지 않습니다. 선택지 후보가 부족한 유형은 생략하며 평가 가능한 문제가 없으면 오류를 표시합니다.
- `KanjiContent`를 상세와 학습 카드가 공유합니다. 없음이 허용된 읽기/연결/예시/팁 섹션은 숨깁니다.
- `SessionController`는 중복 응답과 중복 저장 호출을 차단합니다. 모든 답안을 갖춘 `CompletedSession`만 커밋할 수 있고, 재시도는 동일한 ID와 완료 날짜를 재사용합니다.
- 중간 세션은 저장하지 않습니다. 뒤로 가기는 확인 후 종료하고, 저장 중에는 나가기를 막습니다. 저장 성공 후에만 결과 화면을 표시합니다.

## Phase 3: 로컬 저장

`ProgressRepository.update(transform, sessionId)`가 현재 기록을 읽고, 순수 규칙을 적용한 뒤 하나의 SQLite 트랜잭션에서 기록합니다. `sqflite 2.4.4+1`을 선택했습니다. Android/iOS 플랫폼 구현이며 현재 Flutter 3.47.6/Dart 3.13.5 요구조건에 맞습니다.

SQLite schema v1:

| 테이블 | 역할 |
|---|---|
| `user_progress` | 현재 학년, streak, 마지막 학습 날짜 |
| `kanji_favorite` | 즐겨찾는 한자 ID, 학습 상태와 별개 |
| `kanji_progress` | status, 정오답 횟수, 복습 성공 횟수, review, 최초/마지막 학습 시각 |
| `grade_completion` | 완료 학년, 졸업 축하 확인 여부 |
| `committed_session` | 커밋된 세션 ID로 재시도 중복 방지 |

부분 저장과 중복 점수를 막기 위해 이 네 테이블을 함께 커밋합니다. 작은 MVP라 전체 사용자 상태를 트랜잭션 안에서 교체합니다. SQLite 예외 시 롤백합니다. 향후 schema 변경은 버전별 migration으로 추가하고, downgrade 시 데이터를 삭제하지 않고 오류를 냅니다.

설정은 `shared_preferences 2.5.6`의 캐시 없는 `SharedPreferencesAsync`를 사용합니다. 버전이 있는 단일 JSON 키에 온보딩 완료와 기존 아이콘 설정 모델을 저장합니다. 학습 기록은 preferences에 저장하지 않습니다. 아이콘 모델 값은 아직 기본값이며 해금 기능을 구현한 것은 아닙니다.

패키지의 pub.dev 배포 정보, SDK 범위와 유지보수 저장소를 확인했습니다. iOS 의존성의 최소 버전은 현재 scaffold의 iOS 15.0 범위 안에 있습니다. 테스트용 `sqflite_common_ffi 2.4.3`은 개발 의존성으로만 사용하며 제품의 저장소를 별도 방식으로 이중화하지 않습니다.

## Phase 4: 진도와 복습

- 퀴즈까지 끝낸 세션의 모든 한자를 배운 것으로 기록합니다. 단순 상세 열람·복습 수동 추가는 학습 완료가 아닙니다.
- 정답/오답 횟수는 개별 문제 수입니다.
- `consecutiveCorrect`는 **해당 한자에서 모든 문제를 맞힌 연속 복습 세션 수**입니다. 한 세션에 동일 한자가 여러 문제 나와도 1회로 셉니다.
- 오답 하나라도 있으면 `needsReview=true`, 연속 성공=0. 2회 연속 복습 성공이면 review=false, mastered. 초기 학습 전부 정답은 familiar, 오답이 남으면 learning입니다.
- 수동 복습 추가는 다시 연습할 기회를 만들고 성공 횟수를 0으로 시작합니다. 이미 복습 중인 항목을 다시 추가해 진행을 지우지 않습니다.
- 복습 대상은 마지막 학습이 오래된 순, 동률은 ID 순으로 최대 5자입니다. 진급 후에도 이전 학년 오답을 포함합니다.
- 첫 학습 시각은 보존합니다. 마지막 학습일은 로컬 달력 일자이며 날짜 간격 계산에는 해당 연/월/일의 UTC 값을 사용하여 DST의 23/25시간 날짜 오류를 피합니다. 시계가 과거로 이동하면 streak와 마지막 날짜를 뒤로 돌리지 않습니다. 오늘/어제보다 오래된 streak는 홈에 0으로 표시합니다.

## Phase 5: 학년과 성장

`GradePolicy`는 전체 정원과 로딩된 필수 한자 수가 일치하며 모든 항목에 최초 학습 시각이 있을 때만 완료시킵니다. 제품은 현재 80자이며 전체 코스로 졸업할 수 있습니다. 10자만 배워서는 졸업할 수 없습니다. 누락되거나 중복된 필수 ID가 있으면 완료가 되지 않습니다.

학년은 metadata 순으로 해금합니다. 완료 시 다음 학년으로 `currentGrade`가 이동하며 해당 학년의 식물 단계가 홈에 반영됩니다. 콘텐츠가 없는 2학년은 해금 후에도 준비 중입니다. 잠긴 학년은 시작할 수 없습니다.

세션 결과를 닫은 다음 졸업 축하를 보여줍니다. 확인 전 앱을 종료하면 다음 시작 시 다시 보여주고, 확인 성공 후에는 `seenGradeCelebrations`에 저장해 반복하지 않습니다. 이 상태는 아이콘 해금 모달 상태와 별개입니다.

## Phase 6: 아이콘 보상

`IconPolicy`는 저장된 학년 완료를 기준으로 다음 아이콘을 해금합니다. 기본 새싹 선택을 강제로 변경하지 않습니다. 이미 선택한 해금 아이콘과 확인한 보상 모달은 유지하고, preferences 저장에 실패해도 완료된 학습 진도를 취소하지 않습니다. 재실행 시 SQLite의 학년 완료에서 보상을 다시 계산합니다.

설정의 `/icons` 화면은 잠긴 아이콘의 탭을 막습니다. 해금 모달의 ‘나중에’는 선택을 바꾸지 않고 확인 상태만 저장합니다. 확인 저장 성공 후에는 재표시하지 않습니다. 졸업 모달과 아이콘 해금 모달의 확인 상태는 별도입니다.

`AppIconService`가 지원 여부, 현재 기기 아이콘, 변경을 캡슐화합니다. 지원 환경에서는 기기 변경 성공 뒤 preferences를 저장하고, 저장 실패 시 이전 기기 아이콘으로 복구를 시도합니다. 지원하지 않는 환경은 선택만 저장하며 화면에서 이를 알립니다. 기본 모바일 앱은 `PlatformAppIconService`를 주입하지만 아직 네이티브 핸들러가 없어 지원하지 않는 것으로 처리합니다. Android activity-alias와 iOS alternate icons 연결은 별도 작업입니다.

6개 PNG는 동일한 `PlantPainter`에서 생성합니다. `flutter test tool/export_icons_test.dart`로 재생성할 수 있으며 1학년 이미지의 OS 리소스 크기별 변환은 별도입니다. 기본 새싹 Android/iOS 런처 이미지를 포함했습니다.

## Phase 7–8: 콘텐츠와 마무리

1학년 80자 / 16개 5자 레슨, 기존 10자의 저장 ID와 위치 보존, 공식 목록 대조, 확인한 사전 판 추적. 자세한 과정은 content-verification.md와 content/grade1-audit.json에 있습니다. 대표 읽기와 전체 읽기를 분리해 카드에는 대표 읽기만 표시합니다. 전체 읽기는 퀴즈 오답 제외에 사용합니다. 사전 원문 뜻 `meaningTags`가 겹치는 한자도 뜻 문제의 오답 후보에서 제외합니다. 예를 들어 林과 森의 forest 뜻을 다르게 번역했다는 이유로 서로 오답으로 내지 않습니다. 확인하지 못한 단어는 비워 둡니다.

큰 글씨 해금 모달을 스크롤 가능하게 하고, 320px·글씨 2배의 아이콘 선택과 모달을 검증합니다. 실제 SQLite에서 16개 레슨을 완료하고 다시 열어 졸업, 진급, 복습, 아이콘 선택과 확인 상태 복원을 검증합니다.

## 실제 남은 작업

- Android/iOS 네이티브 아이콘 변경 핸들러와 OS alternate icon 리소스 등록, 실제 기기에서 변경·복구 확인
- Android SDK/Xcode 환경의 빌드, OS preferences 및 SQLite 플러그인, 화면 읽기 도구·한/일 글꼴·앱 종료/재실행 점검
- 스토어 식별자와 서명 확정, 검증된 예시 단어·문장 및 한국어 연결 콘텐츠 확대/감수
- 미완료 세션 재개, 백업, 여러 기기 동기화는 현재 범위에 없습니다.

## 2026-10-09 학습 UX 개선

온보딩은 PageView 안의 스크롤 가능한 카드 3장과 고정 footer 점/버튼으로 구성합니다. `StudyCardsView`는 수직 정보 스크롤과 가로 PageView를 분리하고, `SessionController.showCard`는 카드 위치만 변경합니다. 슬라이드로 앞 카드에 돌아갈 수 있으며 저장은 퀴즈 완료 이후에만 수행합니다.

`startLessonReview(grade, lesson)`은 해금된 학년의 모든 한자를 완료한 레슨에만 복습 세션을 생성합니다. 학습 탭은 콘텐츠가 있는 해금 학년을 선택할 수 있어 진급 후 이전 학년도 복습합니다. 처음 학습 시각과 전체 배운 개수는 반복 복습으로 늘어나지 않습니다.

`UserProgress.favoriteKanjiIds`는 별도 ID 집합이며 SQLite v2의 `kanji_favorite` 테이블에 저장합니다. v1→v2는 새 테이블만 추가합니다. 즐겨찾기 변경도 ProgressRepository의 동일 트랜잭션을 사용하고, 학습·학년 상태를 유지합니다. `FavoriteButton`은 저장 중 중복 탭을 막고 실패를 알립니다.

추가 교육한자 1,026자의 출처 카탈로그는 docs/content에만 있습니다. 한국어 학습 정보의 추가 검증 없이 런타임에 연결하거나 source 영어 뜻을 한국어 뜻으로 대체하지 않습니다.
