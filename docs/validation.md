# Phase 1–8 검증 기록

## 자동 검증

최종 결과: `flutter analyze` 문제 없음, `flutter test` 59개 통과. 포맷 적용 완료.

- Dart 포맷, Flutter 정적 분석
- 기존 콘텐츠 파싱/validation/레슨 순서 및 optional 필드 테스트
- 5자/8문제 생성, 3종 유형, 검증 데이터 기반 선택지, 다른 유효 읽기 제외
- 중복 응답 차단, 저장 실패 후 같은 완료 객체로 재시도
- 오답/정답 누적, 복습 2회 성공·중간 실패, 수동 복습 추가
- 같은 날·다음 날·날짜 공백·과거로 이동한 시계의 streak
- **실제 SQLite 임시 파일** 생성→커밋→닫기→다시 열기. 모든 진행 필드·졸업 확인 복원
- 중간 SQL 제약 오류 시 트랜잭션 롤백, 재시도, 세션 ID 중복 방지, 동시 쓰기의 갱신 보존
- 제품 `AppController` + 실제 SQLite 저장소를 함께 구성해 학습→재생성→다음 레슨→오답 복습→재생성을 검증
- preferences adapter는 테스트용 API 대역으로 직렬화/복원/손상/실패 처리를 검증. OS의 실제 preferences 채널은 기기 검증 대상
- 위젯 테스트에서 온보딩→5카드→8문제→결과→홈→앱 위젯 재생성→복습 2회를 실제 탭으로 진행
- 나가기 확인/종료, 온보딩 저장 실패, 학습 저장 실패, 상세에서 복습 추가, 필터
- 학년 완료→결과 닫기→축하→확인 저장→재생성 후 축하 반복 없음
- 320px 화면/글씨 2배 기본 화면 레이아웃 및 한자 카드의 접근성 탭 액션

Phase 6 구현 후 정적 분석과 전체 54개 테스트를 통과한 다음 Phase 7의 80자를 연결했습니다. 최종 59개 테스트에는 공식 80자 목록 대조, 16개 레슨 완료 후 실제 SQLite 파일 재열기, 졸업·진급·오답 유지·아이콘 보상과 확인 상태 복원이 포함됩니다.

10자 테스트 전용 과정은 화면 흐름을 빠르게 검증하기 위해 유지합니다. 별도로 실제 80자 과정의 졸업을 검증하며, 10자만 학습해도 졸업하지 못하는 테스트도 유지합니다. 제품에 졸업 우회 기능은 없습니다.

- 아이콘 해금 후 자동 선택 변경 없음, 잠긴 아이콘 선택 차단
- 기기 변경 실패 시 이전 선택 보존, preferences 저장 실패 시 서비스의 이전 기기 아이콘 복원 (테스트 서비스 사용)
- 확인한 해금 모달 재실행 시 반복하지 않음, ‘나중에’는 선택을 바꾸지 않음
- 320px/글씨 2배의 아이콘 화면 및 해금 모달 레이아웃, 저장 지원 여부 안내
- 전체 80자에서 여러 난수 seed로 유효한 다른 읽기 및 같은 원문 뜻을 가진 한자의 뜻을 오답으로 내지 않는지 확인
- 식물 아이콘 생성 도구를 별도로 실행해 PNG 6개 생성 성공 (전체 59개 회귀 테스트 수에는 포함하지 않음)
- `flutter build bundle --target-platform=linux-x64 --debug --no-pub` 성공: Dart kernel 및 정적 assets 번들 생성

실행 명령과 클라우드 캐시/통계 설정은 [README](../README.md)에 있습니다. 테스트 대역은 `test/`에만 있습니다. 제품 앱은 항상 SQLite와 플랫폼 preferences를 사용합니다.

## 설치 가능한 환경에서 남은 확인

이 클라우드에는 Android SDK/에뮬레이터와 macOS/Xcode가 없습니다. 기본 Android 대상 번들 빌드는 native build hook에서 SDK 부재로 중단됩니다. `--target-platform=linux-x64`로 Dart 코드와 assets의 디버그 번들을 검증하며, APK/IPA와 네이티브 플러그인의 실제 기기 동작을 확인한 것은 아닙니다.

1. `flutter run`으로 Android/iOS 실행, 최초 온보딩과 한/일 글꼴 확인.
2. 5자 학습 후 일부 오답을 내고 결과→홈의 5/80과 복습 버튼 확인.
3. 앱 강제 종료/재실행: 온보딩 생략, 5/80·오답 상태 복원 확인.
4. 같은 한자 복습을 2회 모두 맞혀 복습 해제 확인. 중간 오답 시 연속 성공 초기화 확인.
5. 미완료 카드/퀴즈에서 종료 시 새 학습이 기록되지 않고 앞서 완료한 기록이 보존되는지 확인.
6. 배운 한자·헷갈리는 한자 필터, 수동 복습 추가, OS 화면 읽기 도구와 큰 글씨 점검.
7. 80자 학습 후 졸업·다음 학년 준비 중·아이콘 해금·확인 후 재실행 검증.
8. **아직 구현하지 않은 OS 아이콘 변경:** Android alias/iOS alternate icon 리소스 등록과 `sukusukukanji/app_icon` 네이티브 핸들러 연결. 지원 여부·현재 아이콘·변경 계약은 Dart에 있으며, 현재는 기기 변경 대신 선택만 저장하고 이를 알림. 실제 런처 캐시·실패 복구·iOS 시스템 알림을 기기에서 확인.

앱 삭제/OS의 저장 공간 삭제는 local-first 기록을 제거할 수 있습니다. 현재 백업·로그인은 제공하지 않습니다.
