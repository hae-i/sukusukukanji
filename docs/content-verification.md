# 1학년 80자 콘텐츠 검증 기록

Phase 6 회귀 테스트(54개)를 통과한 후 2026-10-09에 1학년 콘텐츠를 확장했습니다. 전체 80자 / 16개 레슨이며, 기존 `一 二 三 四 五 六 七 八 九 十`의 ID와 레슨 위치를 유지했습니다. 학습 데이터는 assets에 포함하며 앱 실행 중 네트워크나 AI를 사용하지 않습니다.

## 확인한 출처

- 문부과학성 [학년별 한자 배당표](https://www.mext.go.jp/a_menu/shotou/cs/1319951.htm)의 제1학년 80자 목록과 동일한 집합입니다. 이 페이지는 과거 학습지도요령이며, 1학년 목록을 현재 KANJIDIC2의 grade=1 및 [kanjiapi.dev grade-1](https://kanjiapi.dev/v1/kanji/grade-1) 목록과도 대조했습니다. 2–6학년 콘텐츠를 과거 표로 만들지 않았습니다.
- [KANJIDIC2 원본 XML](https://www.edrdg.org/kanjidic/kanjidic2.xml.gz): 학년, 일본어 음독·훈독, `korean_h` 한자음을 확인했습니다. 신규 70자의 선택한 읽기를 실제 XML의 읽기와 프로그램으로 대조한 뒤 연결했습니다.
- 한국어 위키낱말사전: 훈·음 표 및 한국어/일본어 항목에서 뜻과 단어를 확인했습니다. 신규 항목의 references는 확인한 판의 `oldid`를 포함합니다. JSON에 [출처 판·파일 해시·원본 읽기 기록](content/grade1-audit.json)을 남겼습니다.
- 기존 숫자 10자는 2026-10-08 검증 기록을 유지합니다. `三`의 みっつ는 영어 위키낱말사전도 대조했고, `六`의 육/륙 표기는 한국어 수사 문서와 연결합니다.

## 편집 규칙

대표 읽기만 카드에 표시합니다. KANJIDIC2의 `.`는 오쿠리가나 경계로, 학습 화면에서 제거했습니다. 접두·접미 표시의 `-`를 제거한 전체 읽기는 `allOnyomi` / `allKunyomi`에 보관하고 **퀴즈에서 유효 읽기를 오답으로 내지 않기 위해서만** 사용합니다. 인명 읽기는 넣지 않았습니다. KANJIDIC2 원문 영어 뜻을 meaningTags에 보관하고, 같은 뜻 태그를 가진 한자는 뜻 문제의 오답 후보에서 제외합니다. 화면에서 영어 뜻을 학습 정보로 표시하지 않습니다.

`学/學`, `気/氣`, `円/圓`, `糸/絲`, `虫/蟲`는 일본 문자와 한국 한자 자형을 분리했습니다. `見`, `車`, `金`의 여러 한국 한자음에서는 해당 학습 뜻에 맞는 견·차·금을 선택합니다. `女`는 사전의 오래된 훈 대신 사전 항목에 있는 ‘여자’로 표시합니다. `町`의 한자음 정은 KANJIDIC2, 뜻 마을은 위키낱말사전 일본어 항목으로 확인했습니다.

학교·학생·휴일·연휴·입구 등은 확인한 일본어 단어와 한국어 한자어를 연결합니다. `学校`는 校 항목, `学生`·`先生`는 生 항목, `休日`·`連休`는 休 항목, `入口`는 入 항목을 확인했습니다. `学`에는 校/生 항목도 출처로 추가했습니다.

단어를 확인하지 못한 항목은 examples를 비웠습니다. 연결이 없는 항목도 빈 배열이며 UI에서 해당 섹션을 숨깁니다. 모든 한자에 단어·한국어 연결을 억지로 생성하지 않습니다. 현재 일부 한자에만 예시 단어가 있어, 더 풍부한 단어 및 문장 콘텐츠의 사전 대조와 전문가 감수는 후속 콘텐츠 작업입니다.

## 검증과 수정

- JSON 로더는 중복 ID/문자/레슨 위치, 잘못된 학년·필수 필드·검증일·출처 URL을 거부합니다.
- 테스트는 공식 80자 집합, 16개 5자 레슨, 전체 코스의 퀴즈 생성·졸업·저장 복원을 확인합니다.
- 기본 화면에는 선별한 읽기만 표시하며, source snapshot의 전체 읽기는 정답 제외 목록으로 활용합니다.
- 출처를 다시 확인한 경우에만 `verifiedAt`과 audit을 갱신합니다. CC BY-SA 고지는 앱 설정과 THIRD_PARTY_NOTICES에 있습니다.


## 1학년 예문

`sentences`는 Tatoeba에서 기존 일본어·한국어 번역 쌍을 선별한 정적 데이터입니다. 77자에 연결했고 村·森·糸는 적합한 원문·번역 쌍을 확보할 때까지 비워 둡니다. 일본어와 한국어의 의미 대응·문법·맞춤법을 개별 확인했으며 두 텍스트는 원문 그대로 저장했습니다. 직접 번역과 간접 번역의 여부는 확인 기록에 보존합니다. 간접 번역도 일본어와 한국어의 실제 의미를 따로 대조했습니다. 출처가 있다고 정확성이 자동 보장되는 것은 아니므로 출시 전 일본어 교육 전문가 검수도 권장합니다.

각 언어의 문장 API에서 ID·언어·라이선스와 번역 연결을 확인하고, 작성자와 문장 URL·CC BY 2.0 FR 라이선스를 화면에 표시합니다. 자동 생성된 미검토 후리가나는 사용하지 않습니다. 사람이 검토한 전사만 선택적으로 표시하며 구분 마크업을 읽기 텍스트로 바꿉니다. 읽기 검토자도 별도 출처에 표시합니다. 문장 생성·런타임 API 호출·오디오는 없습니다. `docs/content/grade1-sentences-audit.json`에 ID, 작성자, 본문 SHA-256, 전사 포함 여부, 확인일과 남은 문자를 기록했습니다.

## 중학교 상용한자 과정 배정

2026-10-09에 KANJIDIC2의 `misc/grade=8` 1,110자를 수집했습니다. 사전의 grade=8은 일본 중학교 2학년이 아니라 **초등 교육한자 외의 상용한자 전체**라는 분류입니다. 앱의 과정 ID는 초등학교 1–6, 중학교 7–9로 구분하고 `schoolLevel`/`schoolYear`로 학교급과 학년을 표시합니다.

[2017 중학교 학습지도요령](https://www.mext.go.jp/content/1413522_002.pdf)의 읽기 목표는 중1 추가 300–400자, 중2 추가 350–450자, 중3 나머지 상용한자의 대부분입니다. 문자별 공식 중학교 학년 배당표는 없으므로 **350 / 400 / 360자, 70 / 80 / 72개 레슨**은 앱 자체 배정입니다. 중3에 나머지 전체를 넣는 것은 앱의 완주 목표이며 지도요령이 모든 자의 완벽한 습득을 요구한다는 뜻이 아닙니다.

배정은 KANJIDIC2 신문 사용 빈도순이며 빈도 정보가 없을 때 획수와 Unicode 문자순을 사용했습니다. 빈도는 학습 난이도가 아니며, 한국인 학습자에게 적합한 교육적 순서인지 별도 검토가 필요합니다. 재수집 도구는 기존 배정의 변경을 감지하면 실패하여 사전 갱신으로 학습 순서가 조용히 바뀌지 않게 합니다. 배정을 바꿀 경우 버전과 진도 호환을 함께 검토해야 합니다.

원본 KANJIDIC2와 독립적인 kanjiapi.dev 상용한자 목록을 교차 대조했습니다. API는 Unihan의 자형 변형 네 개를 함께 반환해 2,140 코드 포인트를 포함합니다([API 설명](https://github.com/onlyskin/kanjiapi.dev#list-of-joyo-kanji)). `剥→剝`, `叱→𠮟`, `填→塡`, `頬→頰`를 동일 자종으로 처리한 2,136자 집합이 KANJIDIC2의 초등 1,026자 + 나머지 1,110자와 정확히 일치합니다. 정규화 매핑, 원본 해시와 생성일은 audit에 기록했습니다. 문화청의 [상용한자표](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/kanji/)도 배정 참고 출처입니다.

- `assets/data/middle-school-allocation.json`: 앱에서 오프라인으로 볼 수 있는 배정 문자 목록과 출처.
- `docs/content/middle-school-source-catalog.json`: 원문 음독·훈독·한국 한자음·영어 뜻·빈도·레슨 위치. **검수된 학습 카드가 아니며 학습·퀴즈 데이터에 연결하지 않습니다.**
- `tool/collect_middle_school_kanji.py`: 원본 파일 두 개를 입력받아 집합과 개수를 검증하고 배정/audit을 재생성합니다.

**남은 콘텐츠 작업:** 1,110자의 한국어 뜻, 일본 신자체와 한국 한자 대응, 대표 읽기 선별, 단어 및 한국어 연결 검수 후 중학교 학습 assets를 연결해야 합니다. 초등 2–6학년은 아래 2026-10-13 작업에서 학습 콘텐츠를 연결했습니다. 목록 열람만으로 학습 완료·진도·복습·졸업을 기록하지 않습니다.

## 2026-10-13 초등 2–6학년 학습 콘텐츠 연결

학년별 학습 JSON을 연결하여 초등 **1,026자 / 207개 레슨**을 제공합니다. 학년별로 80/160/200/202/193/191자, 16/32/40/41/39/39개 레슨입니다. 마지막 레슨은 4학년 2자, 5학년 3자, 6학년 1자이며 나머지는 5자입니다. 기존 1학년 파일·ID·레슨 순서는 변경하지 않았습니다.

### 공식 자료가 제공하는 범위

문부과학성의 [2017 개정 학교급별 음훈 배정표](https://www.mext.go.jp/a_menu/shotou/new-cs/1385768.htm)는 한자 옆에 **공식 초등 배당 학년**을 표시하고, 읽기를 초등·중등·고등 단계로 구분합니다. 이 PDF에서 추출한 초등 1,026자의 학년별 집합을 기존 KANJIDIC2 원본 목록과 대조하여 모두 일치함을 확인했습니다. [현행 초등 국어 지도요령 해설](https://www.mext.go.jp/content/20220606-mxt_kyoiku02-100002607_002.pdf)도 확인했습니다. 2–6학년에 과거 1,006자 배당표를 사용하지 않습니다.

공식 자료에는 한국 한자음·한국어 뜻·한국어 연결 설명이 없습니다. **앱의 한국어 학습 데이터 전체가 문부과학성 공식 콘텐츠인 것은 아닙니다.** 한국어 위키낱말사전의 훈·음과 일본어 항목, 영어 위키낱말사전의 한국어/신자체 항목, KANJIDIC2의 읽기·뜻을 별도로 사용했습니다.

### 편집 및 검증 범위

- 새 946자의 한국어 뜻은 출처의 한국어 한자 훈을 우선 사용했습니다. 일본어의 대표 의미와 차이가 있는 `芸`, `台`, `予`, `欠`, `若`, `俵`, `桜`, `駅` 등은 해당 사전 의미를 선별하거나 기록된 KANJIDIC2 영어 의미를 한국어로 옮겼습니다. 번역·편집 여부를 항목별 `meaningBasis`에 기록했습니다. 자동 번역을 대량 실행하지 않았습니다.
- 대표 읽기는 공식 음훈표의 초등 단계 읽기에서 종류별 최대 두 개를 표시합니다. 공식 표에서 초등 단계 독음이 비어 있는 지명용 글자 `媛/岐/滋/阪`는 같은 표의 독음을 사용합니다. 학교급 배정은 지도상의 지침이며 그 밖의 올바른 읽기가 틀렸다는 뜻은 아닙니다.
- 전체 사전 읽기와 공식 표 읽기의 합집합은 `allOnyomi/allKunyomi`로 유지해 유효 읽기가 퀴즈 오답이 되지 않게 합니다. `速`의 はやまる, `務`의 つとまる처럼 사전 snapshot에서 빠진 독음도 공식 표를 근거로 포함합니다.
- 일본 신자체와 한국 자형의 대응은 영어 위키낱말사전의 `ja-kanji/kyu` 및 한국어 표제어를 대조했습니다. 같은 모양의 역사적 글자를 잘못 연결하지 않도록 `芸→藝(예)`, `台→臺(대)`, `予→豫(예)`, `欠→缺(결)`, `担→擔(담)` 등을 반영했습니다. 사전의 한국 한자음 누락/불일치는 대응 자형의 한국어 항목을 확인했습니다.
- **신규 226자**에 확인한 예시 단어, **28자**에 원문에 명시된 한국어 한자어 연결을 넣었습니다. 단어는 일본어 항목의 실제 단어·가나·한국어 뜻 쌍을 개별 선별했습니다. 잘못된 `加わるく/わわる`, `勉强` 등 후보는 제외했습니다. 연결은 원문에서 한국어 단어와 한자 표기가 직접 대응하는 경우만 표시합니다.
- 2–6학년 예문은 아직 추가하지 않았습니다. 단어/한국어 연결이 없는 항목도 빈 배열로 유지합니다. 1학년 77자의 기존 Tatoeba 예문은 그대로입니다.
- 새 학년의 레슨 순서는 공식 음훈표의 문자 순서를 학년별로 추출해 5자씩 고정한 **앱의 편성**입니다. 문부과학성의 공식 수업 순서가 아닙니다. 향후 교육적 순서를 바꿀 때는 기존 진도 호환 검토가 필요합니다.

`docs/content/elementary-audit.json`에 공식 PDF 주소/해시, 공식 학년별 문자 집합, 사전 snapshot 해시, 위키 문서별 언어·판 번호·시각·원문 해시, 훈·음 출처 발췌, 원문 영어 뜻, 공식 읽기/페이지, 단어 발췌와 편집 선택을 기록했습니다. `tool/build_elementary_content.py`는 이 검토 snapshot만으로 정적 assets를 재생성합니다. `--check`로 assets와의 일치를 검사할 수 있습니다. 원문 수집 캐시는 앱에 포함하지 않으며 실행 중 외부 API/AI를 사용하지 않습니다.

이번 검증은 출처 대조·편집 검토와 프로그램 검증이며 **전문 일본어 교육 감수를 받았다는 뜻은 아닙니다.** 대표 의미의 교육적 적합성, 단어/연결 보강, 수업 순서와 전문가 감수는 출시 전 콘텐츠 품질 작업으로 남습니다.

### 중등 자료 조사 결과 — 학습 카드는 아직 연결하지 않음

중등도 상용한자표, 위 음훈표, KANJIDIC2와 위키낱말사전을 조합하면 현재 카드 모델과 같은 항목을 구성할 수 있습니다. 하지만 1,110자 전체의 한국어 뜻·단어·예문까지 모두 갖춘 단일 공식 데이터는 확보하지 않았습니다. 개별 항목 수집·검토가 필요합니다.

[중학교 학습지도요령](https://www.mext.go.jp/content/1413522_002.pdf)은 중1 300–400자, 중2 추가 350–450자, 중3 나머지 상용한자의 대부분이라는 읽기 목표를 제시합니다. 초등과 같은 **문자별 중1/중2/중3 공식 배당표는 없습니다.** 또한 음훈표는 중등과 고등의 읽기를 구분하므로 남은 1,110자의 모든 독음이 중학교 필수 독음인 것은 아닙니다. 기존 앱의 350/400/360자 배정은 자체 편성이며 이번 변경에서는 중등 자료/배정을 수정하거나 학습 카드로 활성화하지 않았습니다.
